
# Gather – Event Management Website

Gather is a responsive event management website that allows users to explore events, view event details, and register for their preferred events.

## Features

- Browse upcoming events
- Search events by name
- Filter events by category
- View event details
- Register for events using a form
- Form validation
- Registration confirmation
- Store registrations using LocalStorage
- Responsive design for different screen sizes
- Animated hero background and event cards
- Dark and light mode

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Project Structure

Gather-Event-Website/
├── assets/

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Purpose

This project was developed as part of the K-Explore Web Designing assignment to demonstrate the use of HTML, CSS, and JavaScript in building a responsive and interactive website.
